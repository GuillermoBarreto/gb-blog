I used to think learning to code meant locking myself in a room with tutorials until I was "ready."

Then I had a conversation about where tech jobs are heading, and I realized I knew nothing about the industry I was trying to join. I could write a for loop. I couldn't tell you what a data center power constraint was.

That bothered me more than I'd like to admit.

So I started reading tech news every morning. Fifteen minutes, coffee, phone. A few weeks in, something shifted — not because I memorized headlines, but because patterns started jumping out. The same tools keep showing up in job posts. The same problems keep getting funded. You start to see where things are going, and that quietly changes what you choose to learn next.

I don't read everything. Tried that, lasted three days. Now it's simple:

```js
// the version I actually kept
const habit = {
  time: "15 minutes, with coffee",
  sources: ["one aggregator", "one community", "one deep dive"],
  output: "one sentence: what changed, and why it matters to me",
};
```

One sentence, in my own words. Some days that sentence is "I have no idea what this means yet." Still counts.

The payoff showed up in interviews. Not because I memorized facts — because I could talk about *why* things matter. "I saw companies hitting power limits training AI models, so I started reading about infrastructure." That's a real conversation. That's different from "I know Python."

Fifteen minutes a day. That's the whole trick. Start tomorrow morning.
